Shot sheet

Every picture, every prompt.

Everything the Kalypt site needs from Higgsfield. Each prompt carries the same look blocks and the same description of the hoodie, word for word, and every later shot takes an earlier one as its reference image, so the same hoodie (and the same person) appears throughout. No prompt asks for text in the picture: type is always HTML.

Automatic (Higgsfield CLI)

  1. npm install once (for the image optimiser).
  2. node higgsfield/generate.mjs prints the plan, the price of every job and the balance. It spends nothing.
  3. node higgsfield/generate.mjs --go runs stage 1 to 4 in order, then the optimiser.
  4. One group or one id: node higgsfield/generate.mjs images --go, … pink-fit --go. Re-roll with --force.

By hand (Higgsfield app)

  1. Copy a prompt below. Use the model and ratio it shows, and attach the named reference image.
  2. Save the download as higgsfield/renders/<id>.png (films: .mp4).
  3. Run node higgsfield/optimize.mjs and reload the site.
